# HR Employee Attrition Analysis (Power BI)

This project is a Power BI dashboard that analyzes HR employee attrition data to uncover trends and insights that impact employee retention and satisfaction.

## 📊 Key Insights:
- Attrition rate by department, job role, and education
- Impact of job satisfaction, age, and income on attrition
- Comparison of active vs. attrited employees
- Visual storytelling using interactive dashboards

## 🛠 Tools & Skills Used:
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Cleaning
- Visualization Best Practices

## 📁 File Included:
- `HR EMP ATTRITION.pbix`: Power BI file containing the full interactive dashboard

## 📌 Project Highlights:
- Identified departments with high turnover rates
- Created KPI cards and bar/line charts for key metrics
- Used slicers and filters for dynamic analysis
